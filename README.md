# CS-360_Inventory_App

Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?

For the inventory app, I plan to create an app that makes it easier for businesses to manage their inventory. Users are able to add, edit, and delete items. Each item has a unique ID, quantity, name, and low-stock threshold. When the low stock threshold is hit for an item, if you are signed up for SMS, you will get an alert on your phone. 

What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful?

The app has 4 main screens, which include login, create account, inventory, and settings. I wanted to keep the overall layout simple and familiar so that navigation is easy for new users. Buttons are clearly labeled so that users can manage their inventory quickly.

How did you approach the process of coding your app? What techniques or strategies did you use? How could those techniques or strategies be applied in the future?

The Android Studio emulator was very useful when testing the functionality of sections. It allowed me to check features like account creation, login, and modifying inventory. Testing made it so that I could find any issues that may occur with the database or overall user interaction to ensure that the app was working as intended before completing it.

How did you test to ensure your code was functional? Why is this process important, and what did it reveal?

To manage the project, I broke it up into smaller sections and worked on one feature at a time, checked that it was working properly, then moved on to the next section. This made it easier to find issues and test each component's functionality before combining all the components together. This is something that I plan on using throughout future projects as it works well for me.

Consider the full app design and development process from initial planning to finalization. Where did you have to innovate to overcome a challenge?

I would say that implementing secure user authentication was where I struggled. I have not worked much with user authentication before this project, so I had to research the different methods of password encryption and change the code to make sure that credentials were being stored securely and not having issues when logging in. 

In what specific component of your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience?

I think the overall inventory management system was successful, and how the database integrated with it. Being able to add, update, and delete items while having those changes update live showed my understanding of Java and SQLite.
